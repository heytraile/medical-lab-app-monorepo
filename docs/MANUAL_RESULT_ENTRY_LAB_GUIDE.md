## 1. What this document covers

Some tests are run on the four main analyzers (Sysmex, Mindray, iFlash, ProLyte). Those results arrive automatically.

**Other tests must be entered by hand** on the **Bench** screen. This guide lists:

- Tests that have a **custom entry form** (specific fields and dropdown choices)
- Tests that use a **simple general form** (one result line plus optional units and reference range)
- A **checklist** for you to sign off or request changes

---

## 2. How staff enter manual results

1. Open the patient’s accession on **Bench**.
2. Find the test under **Manual results** (or similar pending area).
3. Click **Enter** or **Edit**.
4. Fill in the form and save.

The result then appears on the patient record, release queue, and exported reports.

---

## 3. General entry form (used for most manual tests)

When a test does **not** have a custom form below, staff see these fields:

| What staff see | Required? | Examples |
| --- | --- | --- |
| **Result value** | Yes | `12`, `O Positive`, `No growth`, `Non-Reactive` |
| **Units** | No | mm/hr, %, mg/dL |
| **Flag** | No | Normal, High, Low, Critical, Unknown |
| **Reference range — low** | No | Numeric lower limit |
| **Reference range — high** | No | Numeric upper limit |

## 7. Send-out tests (reference laboratory)
